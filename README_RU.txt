МОИ ФИНАНСЫ — Android-проект (v1.1)

Что умеет:
- добавлять доходы и расходы;
- считать общий баланс (отрицательный баланс подсвечивается красным);
- показывать историю операций и дату;
- удалять операцию долгим нажатием;
- хранить данные локально на телефоне;
- тёмная тема оформления.

Сборка APK:
1. Распакуйте архив.
2. Откройте Android Studio.
3. Выберите File -> Open и укажите папку MoiFinansy.
4. Дождитесь завершения Gradle Sync (Gradle 8.9 загрузится автоматически).
5. Выберите Build -> Build Bundle(s) / APK(s) -> Build APK(s).
6. APK появится в app/build/outputs/apk/debug/app-debug.apk.

Требования: Android Studio с Android SDK 35 и JDK 17.
Интернет нужен при первой синхронизации Gradle для загрузки Android Gradle Plugin.
Приложение не требует регистрации и не отправляет финансовые данные в интернет.
Валюта отображается в сумах (UZS).
